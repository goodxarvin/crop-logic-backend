# CropLogic Backend

A Django REST API backend for a smart agriculture and farm operations platform. The project provides business domain services for accounts, farms, crop health, irrigation, soil analytics, alerts, orders, payments, subscriptions, and external integrations.

## Overview

This repository contains the backend services for CropLogic, organized as a modular Django project with domain-specific applications. The system includes:

- authentication and authorization
- farm and agricultural domain models
- device and sensor integrations
- crop health, soil, and irrigation intelligence
- alerts and AI assistant workflows
- commerce, payments, checkout, and subscriptions
- REST API documentation through Swagger/OpenAPI
- Celery background tasks and Redis-based async jobs

## Tech Stack

- Python 3.x
- Django 5.2
- Django REST Framework
- MySQL
- Redis
- Celery
- JWT authentication
- Docker / Docker Compose
- Swagger / drf-spectacular

## Prerequisites

Before running the project, make sure you have:

- Python 3.11+
- pip
- MySQL server or Docker
- Redis
- Optional: Docker Compose

## Local Setup

### 1) Create and activate a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) Configure environment variables

Copy the example environment file:

```bash
cp .env.example .env
```

Then update values such as:

- `SECRET_KEY`
- database credentials
- Redis and Celery URLs
- external service endpoints
- SMS and AI integration keys

### 4) Apply database migrations

```bash
python manage.py migrate
```

### 5) Run the development server

```bash
python manage.py runserver
```

The API will be available at:

- `http://localhost:8000`

## Docker Setup

This project includes Docker Compose configuration for running the backend and dependencies.

```bash
docker compose up --build
```

This can help start the application stack with MySQL, Redis, and related services defined in `docker-compose.yaml`.

## Running Tests

Run the Django test suite:

```bash
python manage.py test
```

Run tests for a specific app:

```bash
python manage.py test farm_hub
```

This project also includes pytest configuration:

```bash
pytest
```

## API Documentation

The project uses `drf-spectacular` to generate OpenAPI/Swagger documentation.

Typical docs endpoints include:

- `/api/schema/`
- Swagger UI and Redoc endpoints generated by drf-spectacular

The project config in `config/settings.py` sets the API title as `CropLogic API`.

## Background Tasks

Celery is configured for asynchronous jobs and scheduled tasks. The backend uses Redis for task broker and result storage.

Common commands:

```bash
celery -A config worker -l info
celery -A config beat -l info
```

## Environment Notes

The application reads configuration from environment variables via `python-dotenv` and Docker environment settings. Values should be kept out of source control. The example file is located at `.env.example`.
